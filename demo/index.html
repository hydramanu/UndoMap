INSTALL THE EXTENSION

One workspace. Two browser packages.

Developer builds, not store-published. The web demo is separate from your installed extension.

Chromium ZIP ↓Firefox ZIP ↓Full source ↓

Chrome, Edge, Brave & compatible Chromium browsers

  1. Extract the Chromium ZIP into a folder.
  2. Open your browser’s Extensions page, enable Developer mode, and choose Load unpacked.
  3. Select the extracted folder containing manifest.json. Pin UndoMap to the toolbar.
  4. Open a webpage and click UndoMap → Scan this page.

Firefox · temporary development install

  1. Extract the Firefox ZIP.
  2. Open about:debugging#/runtime/this-firefox → Load Temporary Add-on.
  3. Select its manifest.json. Temporary add-ons are removed when Firefox restarts. Permanent distribution needs Mozilla signing.

Safari requires a separate Apple app wrapper and signing, and is not included. Browser settings, extension stores, embedded frames and some custom controls cannot be scanned.
